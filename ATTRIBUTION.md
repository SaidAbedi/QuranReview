# Attribution

## Quran Page Images

The Quran page images used in this application are generated from the **QCF (Quran Complex Fonts) V2** typefaces produced by the **King Fahad Complex for the Printing of the Holy Quran** (مجمع الملك فهد لطباعة المصحف الشريف), Madinah, Saudi Arabia.

These fonts are provided for use in non-commercial Quran applications that display the Uthmani script of the Holy Quran. Use of these fonts is subject to the terms set by the King Fahad Complex. Commercial use requires explicit permission.

### Generation Tool

Page images are generated using **[quran.com-images](https://github.com/quran/quran.com-images)**, an open-source tool maintained by the Quran.com team, which renders the QCF V2 fonts to PNG using Perl and ImageMagick.

- Repository: https://github.com/quran/quran.com-images
- Glyph/word boundary data exported from the tool's MySQL database is used for tap-to-word annotation alignment.

### Quran Content Data

Surah/juz mappings, verse keys, and related metadata are sourced from the **Quran.Foundation API** (https://quran.foundation) under their content API terms of service.
